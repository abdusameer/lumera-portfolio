# Reference notes

Reference studied: https://jesperlandberg.com/ (inspected 2026-09-29 at 1440×900 and 390×844, plus its `/llms.txt`).
It is a quality benchmark only. Nothing from it (layout, code, assets, wording, timing) is reused.

## 1. Five abstract principles worth learning

1. **Restraint.** The interface recedes so the work is the loudest thing on screen. Chrome is small and quiet.
2. **Hierarchy by scale, not decoration.** Project media is the largest element on the page; labels and metadata are small, consistent and calm. Nothing competes with the work.
3. **Continuity.** The site behaves like one system rather than a stack of unrelated sections. State changes are connected instead of cut.
4. **Work first.** Selected projects arrive immediately. Capability is proven before it is explained.
5. **An honest plain layer.** A heavy visual experience still ships accurate, machine-readable text. For Lumera this becomes: semantic HTML under every effect, and truthful labels on every project.

## 2. Five recognizable traits we must not reproduce

1. A single full-screen WebGL canvas acting as the entire homepage.
2. Project panels bent into a curved carousel over a 3D floor grid in a black void.
3. Drag- or wheel-to-rotate horizontal project navigation with a grab cursor.
4. Four-corner micro-label chrome (name top-left, profile top-right, featured/full bottom-left, newsletter bottom-right).
5. Its specific transitions and type handling: shared "panel flight" transitions into project routes, glyph-rendered WebGL text, and its self-description wording ("design engineer", the awards line).

## 3. Five ways the Adaptive Frame creates a different identity

1. **A 2D measuring frame, not a 3D gallery.** Lumera's central device is one precise open frame that travels down an editorial page and changes job: open boundary, crop, viewport, facts container, organizing line, index structure, contact field.
2. **The frame states its decision.** A small readout names the frame's current role and its live dimensions. "Start with the problem, then find the right form" becomes visible instead of claimed.
3. **Each project gets the form its real work calls for.** rōk's pour is a scroll-scrubbed crop, Lenny's cocktail recording drives the section color, Stagger's facts sit inside the frame over its media, Motiq opens full width through a mask, and BB's Bakery uses the frame as the boundary between its own pencil sketch and photograph.
4. **Warm ink-and-paper palette, DOM-native type.** Warm near-black, ivory and one gold signal; a variable-width display face that reflows to fit the frame. No WebGL, no floor grid, no void.
5. **Truth on the surface.** Every project shows its classification (Concept Study), year, role, stack and credits, and the capability index separates what has been shown from what is offered.
